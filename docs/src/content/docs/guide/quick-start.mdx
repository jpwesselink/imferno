## Install

<Tabs>
<TabItem label="CLI">

```bash
# Install via npm (prebuilt binaries for all platforms)
npm install -g imferno

# Or via Cargo
cargo install imferno
```

</TabItem>
<TabItem label="Rust">

```toml
[dependencies]
imferno-core = "2"
```

</TabItem>
<TabItem label="Node.js">

```bash
npm install @imferno/node
```

</TabItem>
<TabItem label="WASM">

```bash
npm install imferno-wasm
```

</TabItem>
</Tabs>

## Validate

<Tabs>
<TabItem label="CLI">

```sh
imferno validate /path/to/your.imp
```

</TabItem>
<TabItem label="Rust">

```rust
use imferno_core::package::{Imferno, read_dir, build_report, format_report, ValidationOptions};

let files = read_dir("/path/to/your.imp")?;
let pkg = Imferno::parse(files)?;
let report = build_report(&pkg, &ValidationOptions::default(), None).unwrap();

print!("{}", format_report(&report, false));
```

</TabItem>
<TabItem label="Node.js">

```javascript
import { buildReportFromPath, formatReport } from '@imferno/node';

const report = buildReportFromPath('./my-imp');
console.log(formatReport(report));
```

</TabItem>
<TabItem label="WASM">

```javascript
import { buildReport, formatReport } from 'imferno-wasm';

const report = await buildReport({
    'ASSETMAP.xml': assetmapXml,
    'CPL_def.xml':  cplXml,
    'PKL_abc.xml':  pklXml,
});

console.log(await formatReport(report));
```

</TabItem>
</Tabs>

## Examples

Working examples with full source code are available in the repository:

- **[Node.js example](https://github.com/jpwesselink/imferno/tree/main/examples/node)** — Validate an IMF package with custom rules and typed code constants.

```sh
git clone https://github.com/jpwesselink/imferno.git
cd imferno/examples/node
npm install
npm run validate
```
