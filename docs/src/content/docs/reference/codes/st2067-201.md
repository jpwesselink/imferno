---
title: ST 2067-201 Validation Codes
description: Validation codes from SMPTE ST 2067-201 (IAB Level 0 Plug-in) — editions 2019 and 2021.
---

These codes are emitted when validating the IAB (Immersive Audio Bitstream) Level 0 Plug-in per SMPTE ST 2067-201. Both editions share the same 21 rules; only the year prefix differs.

## Usage

### Rust

```rust
// Import from the barrel re-export
use imferno_core::codes::{St2067_201_2019, St2067_201_2021};
```

### Node.js

```js
import { codes } from '@imferno/node';

codes.ST2067_201_2019; // all codes in this group
codes.ST2067_201_2021; // all codes in this group
```

### WASM

```js
import { codes } from '@imferno/wasm';

codes.ST2067_201_2019; // all codes in this group
codes.ST2067_201_2021; // all codes in this group
```
