---
title: ST 2067-21 Validation Codes
description: Validation codes from SMPTE ST 2067-21 (Application Profile #2E) — editions 2020, 2023, and 2025.
---

SMPTE ST 2067-21 defines Application Profile #2E (App2E), which adds constraints on top of the Core Constraints for UHD, HDR, and advanced audio. Three editions are implemented.

---

## ST 2067-21:2020

| Code | Description | Default Severity | Category |
|------|-------------|-----------------|----------|
| `ST2067-21:2020:7.1/AppIdMismatch` | Application identifier in CPL ExtensionProperties does not match the expected App2E URI. | WARNING | Metadata |
