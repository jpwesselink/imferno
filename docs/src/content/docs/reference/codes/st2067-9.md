---
title: ST 2067-9 Validation Codes
description: Validation codes from SMPTE ST 2067-9:2018 (Sidecar Composition Map).
---

Codes emitted when validating a Sidecar Composition Map (SCM) per SMPTE ST 2067-9:2018. The SCM associates sidecar assets (e.g. Dolby Atmos MXF) with one or more CPLs by UUID without modifying the CPL itself.

## St2067\_9\_2018

| Code | Description | Default Severity | Category |
|------|-------------|-----------------|----------|
| `ST2067-9:2018:6.1/MalformedXml` | SidecarCompositionMap document is not well-formed XML (§6.1). | CRITICAL | Structure |
| `ST2067-9:2018:5/SidecarAssetReferencedByVirtualTrack` | A sidecar asset UUID appears as a TrackFileId in a CPL Virtual Track. Sidecar assets shall not be referenced by Virtual Tracks (§5). | ERROR | Reference |
| `ST2067-9:2018:7.2.3/DuplicateAssetId` | Duplicate SidecarAsset Id within a single SidecarCompositionMap (§7.2.3). | ERROR | Structure |
| `ST2067-9:2018:7.2.4/SignerWithoutSignature` | SidecarCompositionMap contains a Signer element but no Signature element (§7.2.4). | ERROR | Structure |
| `ST2067-9:2018:7.2.5/SignatureWithoutSigner` | SidecarCompositionMap contains a Signature element but no Signer element (§7.2.5). | ERROR | Structure |
| `ST2067-9:2018:7.3.1/SidecarAssetNotFound` | SidecarAsset Id is not present in the package AssetMap (§7.3.1). | ERROR | Reference |
| `ST2067-9:2018:7.3.1.1/CplNotFound` | A CPLId in a SidecarAsset's AssociatedCPLList does not reference a known CPL (§7.3.1.1). | ERROR | Reference |
| `ST2067-9:2018:7.3.1.1/DuplicateCplId` | Duplicate CPLId within a single SidecarAsset's AssociatedCPLList (§7.3.1.1). | ERROR | Structure |
