## Catalogue coverage cross-check

No catalogue codes implemented for ST 430-1. imferno targets IMF
delivery validation; KDM handling is a separate concern (D-Cinema
key delivery, not IMF package validation). If KDM validation were
added, the priorities from Section B would be:
- CompositionPlaylistId resolution against bound CPL
- KeyId-vs-CPL.KeyId cross-reference
- Validity window arithmetic
- Cert chain validity (PKI)

These are all crypto/security concerns and would belong in a
separate ST 430-* validator module, not the IMF engine core.
