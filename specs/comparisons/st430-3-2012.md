## Catalogue coverage cross-check

No catalogue codes implemented for ST 430-3. ETM is a D-Cinema
infrastructure spec; imferno targets IMF (ST 2067) package
validation. ETM handling would live in a separate KDM/security
module if added.

ETM-level signature verification IS conceptually equivalent to
the ST 2067-2 §6.9 CPL signature requirements (both build on
XMLDSig with similar algorithm choices). If a unified signature
verifier were added to the engine, the same code path could
validate ETM and CPL signatures with appropriate algorithm
profile selection.
