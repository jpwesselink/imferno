imferno SMPTE ST 2067
for Rust and JavaScript.

Parse, validate, and inspect IMF packages. Native Rust implementation of the ST 2067 standard family — compiles to WebAssembly for Node.js and the browser.

Full IMF support

Parse AssetMaps, PKLs, and CPLs per SMPTE ST 2067-2, ST 2067-3, and Application profiles including ST 2067-21 and ST 2067-201.

Strict validation

Validate file manifests, SHA-1/SHA-256 hashes, and structural integrity of IMF packages. Hash verification runs on disk; skipped in WASM.

WASM ready

Run the parser in the browser via WebAssembly — the same crate, zero rewrites.

IMF reference corpus

Tested against the Netflix Photon MERIDIAN reference corpus. ST 2067-2, ST 2067-3, ST 2067-21, and ST 2067-201 fully covered.
