imferno SMPTE ST 2067
for Rust and JavaScript.

Parse, validate, and inspect IMF packages. Native Rust implementation of the ST 2067 standard family — with native Node.js bindings and a WebAssembly target for the browser.

Full IMF support

Parse AssetMaps, PKLs, and CPLs per SMPTE ST 2067-2, ST 2067-3, and Application profiles including ST 2067-21 and ST 2067-201.

Strict validation

Over 250 rules across 8 SMPTE standards. Every rule can be set to off, info, warn, error, or critical via config.

Node.js & WASM

Native bindings via @imferno/node for server-side pipelines, plus a WebAssembly build for the browser.

IMF reference corpus

Tested against the Netflix Photon MERIDIAN reference corpus. ST 2067-2, ST 2067-3, ST 2067-21, and ST 2067-201 fully covered.

$ npx

Zero install. Run it once, straight from npm.

npx imferno validate ./my-package # --rules-config rules.json
🦀 cargo install

Install the native Rust binary. Fast, offline, no runtime.

cargo install imferno imferno validate ./my-package
🌐 Browser

Drop XML files below. Everything runs client-side via WebAssembly — nothing leaves your machine.
